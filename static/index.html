Design choices

  • SQLite stores documents, jobs, chunks, and facts across restarts.
  • Background worker claims queued jobs, tracks attempts, retries failures up to three times, and records per-document errors.
  • SHA-256 deduplication prevents duplicate file processing.
  • PDF source locators use page numbers; spreadsheet source locators use sheet names and cell ranges.
  • Reported values and calculated values are represented separately; the FY endpoint exposes missing months.

Known limitations

  • OCR quality can vary; scanned pages with no embedded text need OCR fallback.
  • QA is a transparent baseline, not an LLM-powered semantic reasoner. Unsupported questions should be answered with uncertainty rather than guessed values.
  • Financial-year coverage depends on available source months; calendar-year totals are not automatically treated as complete FY totals.
  • The sample workbook itself has conflicting annual and quarterly totals; discrepancies must remain visible.
